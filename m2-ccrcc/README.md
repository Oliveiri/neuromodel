# README

默认只有**无关区域（0）**和**透明细胞肿瘤区域（1）**。

输出文件中：

- `0` 映射为**蓝色**
- `1` 映射为**黄色**

## 参数说明


| 参数               | 是否必填 | 说明                                     |
| ------------------ | -------- | ---------------------------------------- |
| `--input` / `-i`   | 必填     | 输入图片路径，或包含图片的文件夹路径     |
| `--output` / `-o`  | 必填     | 输出文件夹路径，用于保存映射后的彩色图片 |
| `--weight` / `-w`  | 可选     | 模型权重文件路径                         |
| `--device` / `-d`  | 可选     | 推理设备，默认自动选择`cpu` 或 `cuda:0`  |
| `--classes` / `-c` | 可选     | 前景类别数，不含背景，默认值为`1`        |

## 运行示例

```bash
python predict_batch.py \
  -i exampledata/per_slide/TCGA-A3-3387-01Z-00-DX1.01a24641-ab38-41bc-9151-48e262eb4826/images \
  -o res
```
